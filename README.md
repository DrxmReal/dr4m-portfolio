# Dr4m — Personal Portfolio & Socials

> Personal developer portfolio and socials showcase for **Dr4m** ([@DrxmReal](https://github.com/DrxmReal)).

🌐 **Live Subdomain**: [dr4m.is-a.dev](https://dr4m.is-a.dev)

## ✨ Features
- 🌸 Cute Bento-style layout with live clock & UTC+7 timezone
- 🎧 Integrated background audio player
- 🎮 Live Discord Rich Presence integration via Lanyard API
- 📱 Social links (GitHub, Steam, Discord, YouTube, Facebook, Spotify, etc.)
- 🌌 Ambient aurora glow and animated interactive elements

## 🛠️ Tech Stack
- HTML5 / CSS3 / JavaScript
- Discord Lanyard WebSocket API
- Hosted on Vercel
